# Roadmap

| Fase | Alcance | Estado |
|---|---|---|
| 0 | Auditoría, definición del MVP, arquitectura, documentación y compilación de referencia | Completada con advertencias. APK debug y prueba unitaria verificados |
| 0.1 | Cierre de auditoría, revisión de exclusiones y preparación de Git | Pendiente de inicializar el repositorio local |
| 1 | Gradle, migración de identidad y SDK mínimo, Hilt, navegación e idiomas | Pendiente |
| 2 | Identidad visual, componentes, Bento Grid y animaciones base | Pendiente |
| 3 | Modelos, Room, DAO, repositorios, casos de uso, DataStore y pruebas | Pendiente |
| 4 | Since y Until, CRUD, reinicio, favoritos, categorías y cálculo temporal | Pendiente |
| 5 | Onboarding, inicio, detalle, personalización, plantillas y animaciones | Pendiente |
| 6 | Since Memories, hitos, fotos, timeline, galería y visor | Pendiente |
| 7 | Objetivos, progreso, celebraciones, logros y notificaciones | Pendiente |
| 8 | Widgets con Glance | Pendiente |
| 9 | Estadísticas, historial y contadores inteligentes | Pendiente |
| 10 | Streak, hábitos y calendario | Pendiente |
| 11 | Since Wrapped mensual y anual | Pendiente |
| 12 | Pruebas de calidad, accesibilidad, rendimiento y CI/CD | Pendiente |
| 13 | Identidad definitiva, privacidad, firma, AAB, Google Play y portfolio | Pendiente |
| 14 | Cuentas opcionales, sincronización, funciones compartidas, Wear OS, iOS y opciones premium | Pendiente |

El MVP propuesto se cierra con la fase 5 e incluye las funciones descritas en [FEATURES.md](docs/FEATURES.md). Cada fase requiere autorización antes de comenzar.
