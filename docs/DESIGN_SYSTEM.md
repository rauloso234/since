# Sistema de diseño

La identidad de Since combina superficies tranquilas, números protagonistas y tarjetas redondeadas inspiradas en la organización visual de un Bento Grid. Material 3 aporta la base de componentes y semántica.

| Color | Hex | Uso propuesto |
|---|---|---|
| Midnight | `#17171D` | Base oscura y texto en superficies pastel |
| Lavender | `#BFB0F5` | Acento de marca |
| Mint | `#B4E3CA` | Progreso y acento de tarjeta |
| Peach | `#FAC2AD` | Acento de tarjeta |
| Sky | `#AFCFF9` | Acento de tarjeta |
| Sand | `#F7E3AC` | Acento de tarjeta |

Definir roles semánticos para temas claro y oscuro. Comprobar contraste sobre colores y fotos, escalar tipografía y usar cifras tabulares en contadores. Diseñar tarjetas de varios tamaños, chips, botones, selectores, diálogos y estados de carga, vacío y error. Mantener el orden de lectura y tamaños táctiles al cambiar la cuadrícula. Etiquetar los controles para lectores de pantalla y respetar las preferencias de movimiento. Incorporar transiciones y celebraciones según la fase.
